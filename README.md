# BrewGenge GitHub Pack

Upload `index.html` and the `supabase` folder to the repository root. GitHub repository Settings → Pages → Deploy from branch → main → root.

## Recipe Pack
In Recipe Library choose Export Recipe Pack. Export all recipes, favourites, or BrewGenge originals. Uploaded images are embedded in the JSON and import with the recipe.

## SQL
No additional SQL is needed for recipe pack export/import. Existing private Supabase sync can remain unchanged.
